# WeatherApp

A modern Android Weather Application built from scratch using Java and Android Studio, focused on real-world Android development practices and clean UI design.

---

## Features

* Real-time weather updates using OpenWeatherMap API
* Interactive Map API integration for location-based weather
* 7-day weather forecast
* City search functionality
* Save favourite locations locally
* Current location detection
* Clean dark theme UI
* Multi-screen architecture using Fragments
* Smooth slide transitions with Bottom Navigation Bar

---

## UI Components Used

* Cards
* Grid Layouts
* Horizontal Scroll Views
* Bottom Sheet Dialogs
* RecyclerViews
* Material Design Components

---

## Tech Stack

* Java
* Android Studio
* OpenWeatherMap API
* Google Maps API
* Fragments & Navigation Components
* SharedPreferences / SQLite

---

## Core Functionalities

* Tap any location on the map to get live weather updates
* View 7-day weather forecast
* Search weather by city name
* Save and manage favourite locations
* Detect and display current location weather
* Responsive and clean dark theme interface

---

## Project Goal

This project was built to strengthen practical Android development skills including:

* API Integration
* Modern UI Design
* Fragment-Based Architecture
* Location Services
* Navigation Components
* Local Data Storage

The application was developed as a hands-on learning project to gain experience in building real-world Android applications from scratch.
