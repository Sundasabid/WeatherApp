# WeatherApp

A modern Android Weather Application built from scratch using Java and Android Studio, focused on real-world Android development practices and clean UI design.

#Features
🌍 Real-time weather updates using OpenWeatherMap API
🗺️ Interactive Map API integration for location-based weather
📅 7-day weather forecast
🔍 City search functionality
⭐ Save favourite locations locally
📍 Current location detection
🌙 Clean dark theme UI
📱 Multi-screen architecture using Fragments
🎞️ Smooth slide transitions with Bottom Navigation Bar

#UI Components Used
Cards & Grid Layouts
Horizontal Scroll Views
Bottom Sheet Dialogs
RecyclerViews
Material Design Components

#Tech Stack
Java
Android Studio
OpenWeatherMap API
Maps API
Fragments & Navigation Components
Local Storage (SharedPreferences/SQLite)
Project Goal

This project was built to strengthen practical Android development skills including API integration, modern UI design, fragment-based architecture, and location services.
Built as a hands-on learning project for real-world Android development.
